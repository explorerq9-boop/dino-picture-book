# 恐龙绘本系列《小石头和龙谷邮局》

## 怎么用这份文档

这是一套可以一直写下去的恐龙绘本系列：每集一封“恐龙来信”，小石头和恐龙朋友一起去送信、帮忙，顺便认识一个真实的恐龙知识。

- **想讲故事**：直接读每集的“文字”部分，一页一两句，适合睡前或亲子共读。
- **想做成绘本**：把“画风提示词”贴在每页“画面描述”前面，交给 ChatGPT 或 Gemini 生图，或交给插画师。
- **想让角色每页长得一样**：每次都带上“角色设定”里那段固定外观描述；能用参考图功能的工具，先生成一张满意的角色图，之后每页都用它当参考。
- 每集 12 页左右，一页一个画面，开头和结尾的句子每集都一样，孩子会慢慢熟悉、期待。
