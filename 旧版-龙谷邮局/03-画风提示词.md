# 画风提示词（ChatGPT / Gemini 用）

你发的两张参考图是彩铅加水彩的绘本风：奶油色底、粉蓝和陶土红、细细的铅笔纹理、大面积留白。ChatGPT 和 Gemini 都能直接看懂中文描述，所以下面每页的“画面”都是可以直接复制过去的中文提示词。

**固定画风描述（开始时发一次）**

```
请用儿童绘本插画的风格画图：柔和的彩色铅笔加淡淡的水彩，温暖的奶油色纸张背景，主色调是粉蓝色和陶土红，线条细腻、能看到铅笔纹理，画面安静、温馨，留白多。人物和恐龙都是圆圆的可爱比例，脸颊红红的。恐龙要友善、不吓人，不要尖牙。画面里不要有任何文字。横版 16:9。之后我会一页一页描述画面，请始终保持同样的画风和同样的角色长相。
```

**让画风和角色每页都一样的办法**

1. **一本书用一个对话**：同一集的所有页都在同一个聊天里生成，AI 会记住前面的角色。
2. **第一条消息上传参考图**：把你那两张绘本参考图传上去，说“画风请参考这两张图”，再发上面的固定画风描述。
3. **先做角色定妆图**：让它画“小石头和嘟嘟的角色设定图，正面和侧面，纯奶油色背景”（角色外观用上面表里的描述），满意了保存下来。以后每开一个新对话，都先上传这张定妆图和参考图。
4. **每页开头加一句**：“保持和定妆图一样的角色长相和画风，画这一页：”后面贴该页的“画面”。
5. **画错了就只改一处**：比如“只把嘟嘟的头冠改成陶土橙色，其他都不变”。ChatGPT 和 Gemini 都支持这样的局部修改。
6. **文字自己加**：AI 写中文字容易出错。每页画面里都写了“留白在哪边”，生成后把故事文字放在留白处就行（用手机修图软件、PPT 或 Canva 都可以）。
7. 一页最好不超过三个角色，角色太多 AI 容易画乱。

**分镜：每页的远近、角度和版式**

每页“画面”后面的括号里都标了镜头、角度和版式，生图时把括号里的内容一起贴过去。这样翻书时会有远有近、有大有小，不会每页都一个样子。

| 镜头 | 画什么 | 用在哪里 |
| --- | --- | --- |
| 大远景 / 远景 | 人物很小，重点是风景 | 到达新地方、旅途、告别 |
| 全景 | 角色完整入画，能看到周围环境 | 认识新角色、大家聚在一起 |
| 中景 | 角色半身到全身，重点是动作和对话 | 大部分叙事页 |
| 近景 | 角色的脸和上半身，重点是表情 | 情绪变化的一刻 |
| 特写 / 大特写 | 一个物件或一个细节 | 信、考察本、牙齿这类关键东西 |

| 版式 | 生图时怎么说 | 效果 |
| --- | --- | --- |
| 跨页 16:9 | “横版 16:9，留出一块空白放文字” | 普通页，就是你参考图的样子 |
| 跨页满版 16:9 | “横版 16:9，画面铺满” | 每集一两页的“大场面”，文字压在天空或空地上 |
| 单页竖图 3:4 | “竖版 3:4” | 高的东西（大树、长脖子）或一个人的表情，另半页放文字 |
| 小插图 1:1 | “正方形，纯奶油色背景，物体在中间，四周留白” | 放在文字中间的小图，节奏变慢 |
| 多格分镜 | “一张横图分成三（四）格，格与格之间有白边” | 像漫画，适合“到处找”“乱成一团”这种快节奏的页 |

**每集的分镜节奏模板**（以后每集都照这个写）

1. 第 1 页：中景，固定开场（水坑和信）。
2. 第 2 页：特写或中景，读信。
3. 到达新地方时：一张远景或全景的跨页满版，让孩子“看到”这个地方。
4. 认识新恐龙时：用仰视，显出它的大；如果它很小，就用低角度贴地。
5. 遇到麻烦、角色难过时：近景看表情，或者远一点、大面积留白，让画面安静下来。
6. 翻考察本：永远是正俯视大特写的小插图，每集都一样，孩子一看就知道“要讲知识了”。
7. 解决问题的高潮：跨页满版，镜头拉远或鸟瞰。
8. 最后一页：中景，固定结尾（盖脚印章）。

一集里最好有：至少一张远景大场面、一张小插图、两张以上竖图或近景。不要连续三页都用同一种镜头。快节奏的乱子页可以用多格分镜，但一集最多一页，否则会像漫画而不像绘本。

**生成多格页的小技巧**：AI 一次画多格容易把角色画乱。可以每格单独生成一张正方形小图，再用 PPT 或 Canva 拼成一页。
