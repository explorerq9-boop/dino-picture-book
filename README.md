# 我家有只嘟嘟

给 9 岁孩子的恐龙绘本。恐龙和人生活在一起，恐龙会说话，是小石头的邻居和同学。每集学一个小本领：怎么跟人交流，怎么照顾自己。

- 故事文字用简单的汉字，每个字上面标拼音。
- 每集固定的顺序：遇到一件事 → 用错了方法 → “别急，我们一步一步来” → 分三步学会 → 最后一页是可以剪下来的“三步卡”。
- 每页附有分镜（镜头远近、角度、版式）和画面描述，可以直接交给 ChatGPT 或 Gemini 生图。
