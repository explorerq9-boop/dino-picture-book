# 我家有只嘟嘟

给 9 岁孩子的恐龙绘本。故事里全是恐龙：嘟嘟和朋友们住在恐龙小镇，一起上学、玩耍。每集学一个小本领：怎么跟人交流，怎么照顾自己。

- 故事文字用简单的汉字，每个字上面标拼音。
- 每集固定的顺序：遇到一件事 → 用错了方法，结果不好 → “别急，我们一步一步来” → 三个对比页（✗ 错误做法 / ✓ 正确做法）→ 再试一次，成功 → 前后对比页 → 最后一页是可以剪下来的“三步卡”。
- 每页附有分镜（镜头远近、角度、版式）和画面描述，可以直接交给 ChatGPT 或 Gemini 生图。

## 角色

| 角色 | 是谁 |
| --- | --- |
| 嘟嘟 | 副栉龙，主角。最会数数，看东西很仔细，有时太着急、太大声，听到吵闹的声音会不舒服 |
| 嘟嘟妈妈 | 大一点的副栉龙，系碎花围裙 |
| 龙老师 | 腕龙，脖子长到能从窗户伸进教室 |
| 果果 | 鹦鹉嘴龙，个子小，爱哭也爱笑 |
| 闪闪 | 小盗龙，跑得最快，总是急急忙忙 |
| 角角 | 三角龙，很害羞的新同学 |
| 慢婆婆 | 甲龙，住在小镇门口，说话很慢，很会安慰人 |
| 大嗓门奶奶 | 霸王龙，楼下邻居 |
